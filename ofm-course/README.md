# OFM Course — "Zero to Agency"

Everything needed to launch a low-ticket ($97) course teaching the OFM (OnlyFans Management) agency business model, sold via Instagram organic content into a Skool community.

## Files

| File | Purpose |
|---|---|
| `business-plan.md` | The business model: roles (you vs. your mate), revenue streams, pricing rationale, costs, targets |
| `legal-compliance-checklist.md` | **Read first.** Business setup, ad-policy safety, contract requirements, tax |
| `course-content.md` | The actual course — 8 modules, full lessons, contract template. Source of truth for Skool + the PDF |
| `course-content.pdf` | Sellable/downloadable PDF version of the course (workbook) |
| `instagram-promo-playbook.md` | 20 video hooks, content pillars, posting cadence for your mate's promo videos |
| `skool-setup-guide.md` | Step-by-step Skool community + course build-out |
| `sales-page.html` | Standalone sales/landing page (open in any browser) — can be hosted anywhere or used as reference copy for the Skool page |
| `launch-plan-30-day.md` | Week-by-week plan from build to first 20 sales |

## Suggested order of operations

1. Read `legal-compliance-checklist.md` and `business-plan.md` — sort out the entity + split agreement with your mate before anything else.
2. Set up Skool per `skool-setup-guide.md`, pasting in `course-content.md`.
3. Generate/attach `course-content.pdf` as the downloadable workbook.
4. Adapt `sales-page.html` copy into the Skool community page (or host it separately and link out).
5. Start filming with `instagram-promo-playbook.md`.
6. Follow `launch-plan-30-day.md` day by day.
